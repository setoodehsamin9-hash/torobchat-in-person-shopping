# Torob Chat reference assets

These three unchanged display assets were previously observed and saved from the public Torob Chat asset URLs at the user's explicit request:

- torob-radish.gif: https://chat.torob.com/images/torob_radish.gif
- torob-rotate.gif: https://chat.torob.com/images/torob_rotate.gif
- torob-radish.png: https://chat.torob.com/images/torob_radish.png

Original artwork/marks belong to their respective owner; no original-artwork or affiliation claim is made. This independent hackathon prototype displays the reference mark as requested. Full third-party pages, account captures, proprietary font files and unrelated product assets are not included. The static PNG is used for header, sidebar, welcome, completed/history messages and reduced-motion preference. Only the active in-chat assistant response uses the radish GIF. The saved manifest remains private under data/reference and is excluded from releases.
