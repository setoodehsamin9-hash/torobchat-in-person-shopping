# آماده‌سازی لیارا — هنوز منتشر نشده

ترب‌چت — دستیار خرید حضوری فعلاً محلی است؛ آدرس اصلی مستقیم چت خرید حضوری را باز می‌کند و فروشگاه کاتالوگی جدا حذف شده است. اجرای `liara deploy`، ساخت سرویس پولی یا ارسال credentials فقط پس از تأیید مالک انجام می‌شود. شناسه برنامه، حساب لیارا و DATABASE_URL واقعی هنوز دریافت نشده‌اند.

## مسیر پیشنهادی

یک برنامه Docker واحد برای همه مسیرها و یک PostgreSQL مدیریت‌شده بسازید. `Dockerfile` از Node 22 و خروجی standalone استفاده می‌کند و روی `0.0.0.0:3000` گوش می‌دهد. دیتابیس محلی PGlite برای توسعه است؛ فایل آن را در filesystem موقتی کانتینر production نگه ندارید.

1. PostgreSQL پایدار با دسترسی شبکه خصوصی برنامه تنظیم کنید؛ TLS و CA را مطابق اطلاعات اتصال سرویس تنظیم کنید، نه با غیرفعال‌کردن عمومی اعتبارسنجی گواهی.
2. روی محیط کنترل‌شده با ZIP اصلی و `DATABASE_URL` واقعی، `pnpm db:migrate` و سپس `pnpm data:import` اجرا کنید. `pnpm data:audit` و شمارش سه جدول را مقایسه کنید. raw ZIP در build context یا ریپوی عمومی نباشد.
3. متغیرهای محیطی `.env.example` را در پنل تعریف کنید. `AI_API_KEY` اختیاری است. بدون کلید، حالت قطعی فعال است. `DEMO_CONTACT_MODE=true` فقط برای نمایش پاسخ شبیه‌سازی‌شده است.
4. `pnpm lint && pnpm typecheck && pnpm test && pnpm build` را اجرا کنید. سپس تصویر `docker build -t torob-inperson .` ساخته می‌شود. اجرای Docker نیازمند دسترسی Docker است؛ موفقیت آن بدون اجرای واقعی ادعا نمی‌شود.
5. بعد از تأیید مالک، برنامه Docker را با پورت 3000 و متغیرهای سروری منتشر کنید. فایل `liara.json` فقط پورت را تنظیم می‌کند؛ شناسه برنامه را مالک در جریان استقرار انتخاب می‌کند.
6. `/api/health` باید ok=true و شمارش صحیح داشته باشد؛ سپس با `SMOKE_BASE_URL=https://YOUR_REAL_DOMAIN pnpm smoke` تمام مسیرها، ابزارها و فیلترها را روی URL واقعی بررسی کنید. آدرس بالا نمونه است و لینک دیپلوی نیست.

## ظرفیت و عملیات

حداقل ظرفیت را پس از اندازه‌گیری حافظه و latency محیط واقعی انتخاب کنید؛ این تحویل هیچ پلن پولی نمی‌خرد. داده و indexها باید روی PostgreSQL مستقل باشند. backup و سقف اتصال Pool متناسب با منابع، log بدون متن تماس/مختصات دقیق، health و زمان پاسخ جست‌وجو را پایش کنید. توسعه محلی PGlite هم‌زمان توسط چند فرآیند جداگانه باز نشود؛ import را پیش از server انجام دهید.

مستندات رسمی بررسی‌شده در ۲۰۲۶-۱۰-۲۲: [استقرار Next.js](https://docs.liara.ir/paas/nextjs/how-tos/deploy-app/)، [راهنمای رسمی لیارا در GitHub](https://github.com/liara-cloud/docs/blob/master/src/pages/paas/nodejs/how-tos/deploy-app.mdx)، [containerize Next.js در Docker](https://docs.docker.com/guides/nextjs/). schema/config Docker بر اساس build واقعی همین کد ارزیابی می‌شود؛ provision و شبکه/اعتبار حساب لیارا هنوز آزموده نشده است.


برای 9router محلی، نشانی `localhost:20128` فقط روی همین میزبان معتبر است. پیش از انتشار، سرویس مدل قابل دسترس HTTPS و کلید سمت سرور تنظیم کنید؛ [راهنمای 9router](ai-9router.md) را ببینید. سقف روزانه برنامه مستقل از صورتحساب بالادستی است.


## بستهٔ تمیز این نسخه

از `npm run release:check` و سپس `npm run release:source` استفاده کنید. فایل ZIP در `releases/` فقط سورس، وابستگی‌نامه، migration، راهنما و `.env.example` بدون کلید دارد؛ ZIP خام، دیتابیس و فایل خصوصی حذف می‌شوند. پوشهٔ داده را از دستگاه خود پاک نکنید؛ فقط خارج از بسته بماند. بسته پس از استخراج به `npm ci` و build و واردکردن جداگانه دیتاست نیاز دارد.

## امکانات وابسته به سرویس

- نشان: `NESHAN_API_KEY` سمت سرور؛ [راهنمای نشان](neshan.md). بدون کلید، نقشهٔ OSM و فهرست واقعی کار می‌کنند و زمان رسیدن نامشخص است.
- LLM/امبدینگ: `AI_*` و `EMBEDDING_*` از محیط میزبان خوانده می‌شوند. هیچ کلیدی داخل ZIP نیست. `localhost:20128` روی لیارا به کامپیوتر کاربر اشاره نمی‌کند. نبود کلید، حالت قطعی شفاف دارد.
- استعلام: شبیه‌سازی پایدار و رایگان است. فعال‌سازی تماس/SMS واقعی به درگاه مستقل، فهرست مخاطب معتبر با مجوز، تعرفه و سقف هزینه و تأیید جداگانه مالک نیاز دارد؛ [قرارداد کامل درگاه](contact-gateway.md). همه شماره‌های دیتاست غیرقابل استفاده‌اند.
- worker و وب باید PostgreSQL مشترک داشته باشند. `docker build --target worker` فقط تصویر ابزار یک‌مرحله‌ای می‌سازد و دستور پیش‌فرض آن dry-run است. زمان‌بند فقط پس از تأیید مالک و پیکربندی واقعی می‌تواند `--dispatch-approved-live` را اجرا کند. حلقهٔ پس‌زمینه در درخواست وب یا وعدهٔ تماس واقعی شبیه‌سازی‌شده وجود ندارد.

## مرز آمادگی تولید

این یک نمونه قابل تست و بستهٔ آمادهٔ پیکربندی است؛ هنوز انتشار تولید یا زیرساخت تماسِ تأییدشده نیست. پیش از انتشار عمومی، آدرس HTTPS واقعی، PostgreSQL پایدار و extension vector، backup، محیط کلیدها، زمان‌بند worker، callback امن و مخاطبان معتبر را آماده کنید. شناسه پیگیری فعلی یک قابلیت محرمانهٔ همان مرورگر است؛ بازیابی چنددستگاهی و احراز هویت حساب کاربری پیاده نشده‌اند. Redis/پرداخت اینترنتی/شارژ کیف پول یا سرویس تلفنی خریداری نشده است.

منابع رسمی دوباره در ۲۳ اکتبر بررسی شدند: [استقرار Docker در لیارا](https://docs.liara.ir/paas/docker/how-tos/deploy-app/) و [استقرار Next.js](https://docs.liara.ir/paas/nextjs/how-tos/deploy-app/). استفاده از راهنمای آماده‌سازی، مجوز اجرای deploy نیست.
