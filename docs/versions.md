# دو نسخهٔ ترب‌چت

دو ZIP از یک نسخهٔ سورس ساخته می‌شوند؛ منطق ایجنت، داده و UI مشترک است. هر دو نسخه اجازه می‌دهند مدل با ابزارهای محدود دیتاست را بخواند و پس از دریافت نتیجه، پاسخ نهایی را بسازد. هیچ‌یک پیش از بررسی مدل، پنل جست‌وجوی مستقلی نمایش نمی‌دهند.

| مشخصه | optimized | boxapi |
| --- | --- | --- |
| تنظیمات خصوصی | `.env.local` | `.env.boxapi.local` |
| پورت پیش‌فرض | 3100 | 3101 |
| پوشهٔ build | `.next-optimized` | `.next-boxapi` |
| ارائه‌دهنده | مطابق تنظیمات مالک | BoxAPI با Base URL مشخص |
| مدل پیش‌فرض نمونه | gpt-6-luna | gpt-6-luna |
| fallback بدون کلید | صریح و مبتنی بر DB | صریح و مبتنی بر DB |

## انتخاب پروفایل

`npm run dev:optimized` یا `npm run dev:boxapi`. برای build و start به‌ترتیب `npm run build:<profile>` و `npm run start:<profile>` را اجرا کنید. توسعهٔ عادی با `npm run dev` نیز از `.env.local` استفاده می‌کند.

در نصب تازه، `.env.example` را به فایل خصوصی همان پروفایل کپی کنید. هیچ‌گاه فایل کلید موجود را بازنویسی نکنید. در نسخه BoxAPI کلید از `.env.boxapi.local` یا `BOXAPI_API_KEY` خوانده می‌شود؛ کلید یک ارائه‌دهندهٔ دیگر در `.env.local` خودکار به BoxAPI منتقل نمی‌شود. `BOXAPI_MODEL` امکان override نام مدل این پروفایل را دارد.

`AI_MAX_REQUESTS_PER_TURN=3`، `AI_MAX_TOOL_CALLS=6`، `AI_MAX_OUTPUT_TOKENS=800` و `AI_TIMEOUT_MS=30000` سقف محلی هستند. مسیر سادهٔ موفق معمولاً شامل انتخاب ابزار و یک درخواست بعدی برای بررسی شواهد است. اگر سقف قبل از بررسی نهایی تمام شود، `review_incomplete` گزارش می‌شود؛ نتیجه به‌عنوان پاسخ کامل مدل معرفی نمی‌شود. هر تغییر سقف هزینه باید با بودجهٔ مالک سازگار باشد.

## دادهٔ مشترک

ورود CSV فقط هنگام آماده‌سازی DB انجام می‌شود. پیام کاربر به SQL/ابزارهای همان DB وصل است؛ کل آرشیو برای LLM ارسال نمی‌شود. در هر نتیجه شناسهٔ محصول، فروشگاه و پیشنهاد حفظ می‌شود. درخواست‌های صریح کارت مثل «فروشگاه‌های همین کالا» می‌توانند مستقیم روی داده اجرا شوند و برچسب اقدام مستقیم دارند؛ پیام آزاد و پیشنهادهای شروع از مسیر مدل می‌گذرند.

برای PostgreSQL، `DATABASE_URL` یکسان را در هر دو فایل و محیط ورود داده قرار دهید. برای PGlite فقط یک فرایند مالک هر پوشه باشد؛ جابه‌جایی بین نسخه‌ها نیازمند توقف سرور قبلی است. برای دو DB مستقل، `PGLITE_PATH` متفاوت بدهید و هرکدام را کامل وارد کنید. عملیات `data:import` و `db:migrate` تنظیمات `.env.local` را می‌خوانند؛ برای DB دوم، متغیر مقصد را صریحاً در محیط همان دستور قرار دهید.

## خروجی سورس

```bash
npm run release:optimized
npm run release:boxapi
```

بسته‌ها `EDITION.md` و `.env.example` متناسب با پروفایل دارند؛ کلیدها خالی‌اند. مسیر خروجی به‌ترتیب `releases/torobchat-optimized-source.zip` و `releases/torobchat-boxapi-source.zip` است. فایل موجود بازنویسی نمی‌شود. این بسته‌ها سورس‌اند و نیازمند نصب وابستگی، ورود جداگانهٔ داده و build هستند.
