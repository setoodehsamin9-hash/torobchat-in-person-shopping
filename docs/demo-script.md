## آماده‌سازی

- `npm ci`، ورود کامل دیتاست و سلامت `GET /api/health`.
- پروفایل مناسب: `npm run dev:boxapi` یا build/start همان پروفایل. کلید خصوصی در `.env.boxapi.local`.
- قبل از ضبط، یک پیام محدود واقعی به مدل بفرستید و `mode=provider` بدون `fallback_reason` را بررسی کنید؛ صرف دیدن فهرست مدل‌ها کافی نیست.
- اگر کلید یا سرویس آماده نیست، برنامهٔ قابل اجرا را با برچسب «حالت قطعی» نشان دهید و ادعای استفاده از LLM در آن پاسخ نکنید.
- تست نقشه با قطع tile هم در سناریوهای مرورگر انجام می‌شود؛ در دمو اینترنت و تصاویر خارجی را جدا بررسی کنید. فهرست فروشندگان جایگزین نقشه است.
- برای مقایسه فروشنده، دو offer از همان product_id انتخاب کنید. برای موجودی یا تماس نتیجهٔ واقعی جعل نکنید.
- `DEMO_CONTACT_MODE=true` و `CONTACT_REAL_MODE=false` باقی بمانند. API مسیریابی نشان بدون کلید و اجازهٔ لازم فعال معرفی نشود.
