# اتصال BoxAPI برای هکاتون

بر اساس اطلاعات پنل هکاتون که مالک ارائه کرده و [مستندات رسمی](https://boxapi.ir/docs/ai/)، Base URL برابر `https://ai.boxapi.ir/ai/v1` و endpoint چت `/chat/completions` است. نمونهٔ پیش‌فرض این پروژه `gpt-6-luna` است؛ نام مدل از `AI_MODEL` قابل تغییر است. پشتیبانی نام مدل در پنل به معنی آزمون موفق function calling در این workspace نیست.

## تنظیم خصوصی

در نصب تازه `.env.example` را به `.env.boxapi.local` کپی کنید، سپس `AI_API_KEY` را فقط در همان فایل یا در محیط امن سرور قرار دهید. فایل موجود را بازنویسی نکنید. اجرا: `npm run dev:boxapi`؛ بررسی فقط‌خواندنی فهرست مدل‌ها: `npm run ai:check`. این بررسی تولید متن و ابزار را آزمایش نمی‌کند. کلید در مرورگر، README، Git و بستهٔ ZIP قرار نمی‌گیرد.

سقف‌های پیش‌فرض: سه درخواست مدل در هر پیام، شش ابزار داده، هشتصد توکن خروجی در هر درخواست، صد درخواست روزانه و مهلت کل نوبت سی ثانیه. این‌ها سقف برنامه‌اند و جایگزین تعرفه/اعتبار سرویس نیستند. برای Luna، مسیر سازگاری فعلی از `max_completion_tokens` و `reasoning_effort=none` استفاده می‌کند؛ تست آفلاین payload را کنترل می‌کند. اجرای زنده نیازمند کلید مالک است.

## جریان پاسخ

مدل ابزار سرور را درخواست می‌کند؛ سرور پارامترها، شناسه‌ها و محدودیت‌های خرید را اعتبارسنجی و رکوردها را برمی‌گرداند. نتیجهٔ ابزار برای درخواست بعدی مدل ارسال می‌شود. مدل می‌تواند با `finishShoppingTurn` و شناسه‌های واقعی، پیشنهادهای نهایی را انتخاب/مرتب کند. تنها متن نهایی کنترل‌شده و کارت‌های معتبر یک‌بار در رابط نشان داده می‌شوند. مرحلهٔ جست‌وجو فقط پیام وضعیت دارد.

همان پیام مدل که ابزار داده را درخواست کرده، هنوز نتیجهٔ آن را نخوانده است؛ پایان کنار آن ابزار برای شواهد تازه پذیرفته نمی‌شود. اگر بودجه/مهلت پیش از بررسی تمام شود، `review_incomplete` یا خطای مشخص گزارش می‌شود و پاسخ کامل LLM ادعا نمی‌شود.

## امبدینگ مستقل

`EMBEDDING_ENABLED=false` پیش‌فرض است. برای این جریان، LLM می‌تواند مستقیماً ابزارهای جست‌وجوی DB را بخواند؛ ساخت بردار کل داده لازم نیست. مدل چت و مدل برداری جای هم استفاده نمی‌شوند. هیچ ایندکس انبوه، درخواست امبدینگ یا مصرف تازه در build/start خودکار نیست.

## وضعیت این workspace

کلید مالک در فایل‌های خصوصی سرور تنظیم و اتصال واقعی با gpt-6-luna بررسی شد. در production و مرورگر، «لامپ میخوام» چهار پیشنهاد واقعی و سؤال طبیعی کاربرد داد؛ ادامهٔ همان گفتگو با سقف ۳۰۰ هزار تومان پنج پیشنهاد داخل بودجه داد. هر دو mode=provider و بدون fallback بودند؛ هرکدام دو درخواست مدل داشتند. زمان‌های نمونه حدود ۹٫۲ و ۷٫۸ ثانیه‌اند و تضمین عمومی کارایی نیستند. کلید در سورس یا بستهٔ انتشار نیست؛ نمونهٔ env همچنان خالی است.

در models، شناسهٔ همان مدل به شکل openai/gpt-6-luna آمده است؛ نام کوتاه در تست Chat Completions پذیرفته شد. checker هر دو شکل را پشتیبانی می‌کند. متن طبیعیِ سؤال نیازسنجی حفظ می‌شود، اما ادعاهای قیمت/موجودی همچنان به کارت‌های معتبر محدودند. [گزارش دقیق بررسی](../STATUS.md) مرجع آخرین وضعیت است.
