> اتصال فعال طبق درخواست جدید به BoxAPI و gpt-6-luna منتقل شده است؛ این سند راهنمای تاریخی/اختیاری 9router است. راهنمای فعلی: [BoxAPI](ai-boxapi.md).

# اتصال محلی به 9router

در این دستگاه 9router در `http://localhost:20128/dashboard/` اجرا می‌شود. برنامه از API سازگار با OpenAI در `http://localhost:20128/v1` استفاده می‌کند. تنظیمات و کلید موجود در فایل خصوصی `.env.local` ثبت شده‌اند؛ کلید وارد کد مرورگر یا این راهنما نشده است. این الگو مطابق [مخزن رسمی 9router](https://github.com/decolua/9router) است.

```dotenv
AI_PROVIDER=9router
AI_BASE_URL=http://localhost:20128/v1
AI_API_KEY=کلید_موجود_در_داشبورد
AI_MODEL=oc/deepseek-v4.1-flash-free
AI_MAX_REQUESTS_PER_TURN=3
AI_MAX_TOOL_CALLS=6
AI_MAX_OUTPUT_TOKENS=800
AI_DAILY_REQUEST_LIMIT=100
AI_TIMEOUT_MS=60000
```

مدل انتخاب‌شده در ۲۳ اکتبر به درخواست کاربر DeepSeek با شناسهٔ بالا است؛ این شناسه از فهرست واقعی مدل‌های 9router خوانده شد. امبدینگ مستقل روی BoxAPI باقی می‌ماند. عبارت free در شناسه مدل، تضمین سهمیه یا هزینه سرویس نیست.

برای تغییر مدل، شناسه دقیق مدل موجود در داشبورد را در `AI_MODEL` بگذارید و برنامه را مجدداً اجرا کنید. کلید را در چت یا متغیرهای `NEXT_PUBLIC_` نگذارید. متغیرهای خصوصی مدل هنگام اجرای سرور خوانده می‌شوند؛ برای تغییر صرفاً این متغیرها بازراه‌اندازی کافی است. پس از تغییر کد، build تازه بگیرید.

```bash
npm run build
bash START_LOCAL.sh
```

بررسی بدون ارسال پیام به مدل، با Node 22 یا جدیدتر:

```bash
node --env-file=.env.local --import tsx scripts/check-ai-connection.ts
```

در بررسی اولیهٔ ۲۲ اکتبر، endpoint فهرست مدل‌ها HTTP 200 داد و مدل قبلی `ag/gemini-3.8-flash-low` در میان ۳۱ مدل موجود بود؛ در آن مرحله chat completion اجرا نشد. بررسی ۲۳ اکتبر حضور شناسهٔ DeepSeek بالا را نیز تأیید کرد. فهرست مدل‌ها به‌تنهایی پشتیبانی عملی tool calling، سهمیه حساب یا کیفیت پاسخ مدل را اثبات نمی‌کند؛ نتایج اجرای واقعی در STATUS.md ثبت می‌شوند.

## مصرف و محدودیت

هر نوبت گفتگو حداکثر سه درخواست مدل و شش ابزار داده دارد. ابزارهای دیتابیس به‌خودی‌خود درخواست پولی مدل نیستند؛ مدل ممکن است برای دیدن نتیجه ابزار و انتخاب مرحله بعد دوباره فراخوانی شود. حداکثر خروجی هر درخواست ۸۰۰ توکن است؛ ورودی، تعریف ابزارها و احتمال توکن‌های داخلی سرویس جدا هستند. تاریخچه به شش پیام کوتاه و شواهد ابزارها به مجموعه‌ای محدود خلاصه می‌شوند. پاسخ نهایی و قیمت‌ها از داده معتبر و متن سمت سرور ساخته می‌شوند.

بودجه برنامه روزانه ۱۰۰ درخواست است، نه ۱۰۰ گفتگو یا مبلغ مشخص. با سه درخواست در هر نوبت، حدود ۳۳ نوبت کامل پرمصرف در سقف جا می‌گیرد؛ برخی نوبت‌ها یک درخواست دارند. رزرو درخواست در جدول `ai_usage_daily` به شکل اتمی ثبت می‌شود؛ خطا یا قطع ارتباط هم ممکن است یک رزرو مصرف کند. شمارنده در منطقه زمانی تهران عوض می‌شود و با راه‌اندازی مجدد سرور پاک نمی‌شود. توکن‌ها فقط در صورت گزارش سرویس جمع می‌شوند؛ این عدد، صورتحساب معتبر سرویس نیست. صفحه `/settings` و مسیر `/api/ai/status` وضعیت بدون کلید را نشان می‌دهند.

پس از قطع سرویس، timeout یا اتمام سقف محلی، مسیر قطعی با برچسب شفاف فعال می‌شود. مهلت کل نوبت مدل اکنون ۶۰ ثانیه است؛ تست محدود DeepSeek حدود ۳۳ ثانیه طول کشید و با مهلت قبلی ۳۰ ثانیه سازگار نبود. سقف روزانه از مصرف نامحدود همین برنامه جلوگیری می‌کند؛ سهمیه 9router و سرویس بالادستی مستقل است و تضمین رایگان بودن یا تمام نشدن آن نیست. برای کاهش بیشتر، سقف روزانه یا تعداد درخواست هر نوبت را کم کنید؛ محدود کردن نوبت به یک درخواست، زنجیره چندمرحله‌ای را کوتاه می‌کند. هیچ retry نامحدودی وجود ندارد.

داشبورد فعلی Antigravity متصل دارد و خودش درباره استفاده از اتصال OAuth از طریق پراکسی و احتمال محدودیت حساب هشدار می‌دهد. حساب یا اتصال دیگری ساخته نشده و تنظیمات ارائه‌دهنده تغییر نکرده است. انتخاب مدل دیگر یا API رسمی بعداً با تنظیم متغیرها ممکن است.

## منطق ایجنت و وضعیت انتشار

متن فعلی + زمینه کوتاه → استخراج وضعیت خرید → انتخاب ابزار توسط مدل → اعتبارسنجی Zod و اعمال فیلترهای سرور → خواندن رکوردهای واقعی → بلوک‌های تایپ‌شده رابط. ابزار ثبت نتیجه استعلام در دسترس مدل نیست؛ فقط اقدام صریح کاربر آن را ثبت می‌کند. متن آزاد مدل برای ادعای قیمت، موجودی و تأیید فروشنده نمایش داده نمی‌شود. چارچوب این نسخه runtime اختصاصی سازگار با OpenAI است؛ LangChain یا LangGraph نصب نشده‌اند.

روی Liara، `localhost:20128` به همین کامپیوتر اشاره نمی‌کند؛ برای انتشار باید سرویس مدل روی میزبان قابل دسترس HTTPS با تنظیم امن قرار گیرد و `AI_BASE_URL` تغییر کند. این مرحله و هر انتشار تولید نیازمند تأیید کاربر است؛ هیچ تونل عمومی یا انتشار تولید ایجاد نشده است.
