# منبع، اعتماد و حریم خصوصی

- هر محصول/آفر/فروشگاه به شناسه رکورد CSV اصلی قابل ردیابی است؛ دسته فروشگاه نشانه آفر یک محصول نیست.
- مبلغ دقیق تومان است. قیمت NULL، زمان نامعلوم، موقعیت ناقص و ساعات پشتیبانی‌نشده «نامشخص» هستند.
- قیمت ثبت‌شده و ساعات اعلام‌شده اثبات زنده بودن قیمت، موجودی یا بازبودن نیستند. timestamp و سن قیمت باید کنار آفر دیده شوند.
- تلفن‌های دیتاست ساختگی‌اند و برای تماس، SMS یا WhatsApp استفاده نمی‌شوند. نام بیشتر فروشگاه‌ها ناشناس‌سازی شده است. شناسه آفر کلید مقایسه است، نه نام فروشگاه.
- اقساط strict فقط با channel=in_person و محدودیت قیمت/دسته معتبر پذیرفته می‌شود؛ unknown نیازمند بررسی است.
- پاسخ «موجود» در شبیه‌سازی، تأیید فروشنده نیست. provenance و زمان ثبت مجزا ذخیره می‌شود. هیچ مسیر API این نمونه seller_confirmed تولید نمی‌کند.
- لینک خارجی منتشرشده فقط با کلیک کاربر باز می‌شود؛ ارتباط خودکار یا scraping نداریم. قبل از تماس واقعی و انتشار production تأیید مالک لازم است.
- انتخاب GPS با کنش مستقیم کاربر انجام می‌شود. گزینه محله و پین دستی بدون GPS موجود است. فاصله خط مستقیم است و ETA نیست.
- نقشه از tileهای OpenStreetMap با attribution و cache مرورگر استفاده می‌کند. دانلود دسته‌ای و prefetch نقشه نداریم. آزمون‌های headless درخواست tile خارجی را مسدود می‌کنند؛ خطای شبکه با فهرست واقعی جبران می‌شود. [سیاست رسمی tile](https://operations.osmfoundation.org/policies/tiles/).
- کلید AI فقط سمت سرور، فایل‌های محیطی و ZIP/DB خارج از Git و تصویر Docker قرار دارند.
