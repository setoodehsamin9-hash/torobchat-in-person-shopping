# ترب‌چت | دستیار خرید حضوری تهران

**اول مطمئن شو، بعد راه بیفت.**

ترب‌چت یک نمونهٔ مستقل هکاتون است که انتخاب کالا، یافتن فروشنده، مقایسهٔ پیشنهادها و برنامهٔ مراجعه را در یک گفت‌وگوی فارسی و راست‌به‌چپ جمع می‌کند. اطلاعات کالا و قیمت از دیتاست واقعی چالش می‌آیند؛ مدل از طریق ابزارهای سرور به آن‌ها دسترسی دارد.

**رفتار اصلی:** پیام کاربر ← انتخاب ابزار توسط مدل ← خواندن رکوردهای دیتابیس ← بررسی نتیجه توسط مدل ← یک پاسخ نهایی و کارت‌های مرتبط. هیچ پنل جست‌وجوی اولیه پیش از بررسی مدل نمایش داده نمی‌شود.

این پروژه وابسته به ترب نیست و هیچ تغییری در `torob.com` یا `chat.torob.com` ایجاد نمی‌کند.

[اجرای دو نسخه](docs/versions.md) · [ارائهٔ هکاتون](docs/hackathon-pitch.md) · [سناریوی دمو](docs/demo-script.md) · [معماری](docs/architecture.md) · [ممیزی داده](docs/data-audit.md) · [وضعیت بررسی‌ها](STATUS.md)

**سه سناریوی قابل ارائه:** صفحهٔ [دمو](http://localhost:3101/demo) در پروفایل BoxAPI، با پیام آماده و شروع مستقل برای هدفون، لپ‌تاپ اعتباری و لوستر. [متن گوینده و مراحل پنج‌دقیقه‌ای](docs/demo-scenarios-fa.md).

## قابلیت‌ها

- گفت‌وگوی فارسی با حفظ بودجه، محدوده، محصول انتخاب‌شده و شرط اقساط حضوری.
- اتصال سروری به BoxAPI با ابزارهای اعتبارسنجی‌شده؛ مدل می‌تواند پیشنهادهای واقعی را انتخاب و مرتب کند.
- حداکثر پنج پیشنهاد از فروشگاه‌های متفاوت؛ جزئیات، مقایسه و نمایش منبع رکورد.
- نقشهٔ تعاملی و کارت‌های روشن با تصویر کالا، قیمت قرمز به تومان و وضعیت ثبت قیمت.
- انتخاب موقعیت دستی یا GPS با اجازهٔ کاربر؛ فهرست فروشندگان هنگام قطع نقشه همچنان کار می‌کند.
- استعلام نمایشی و برنامهٔ مراجعه؛ تماس واقعی و مسیریابی خارجی نیازمند تنظیم و مجوز مستقل‌اند.
- حالت جایگزین شفاف در نبود کلید، قطع سرویس یا تکمیل‌نشدن بررسی مدل.

## دو نسخه از یک کد مشترک

| نسخه | کاربرد | تنظیمات خصوصی | اجرای توسعه |
| --- | --- | --- | --- |
| `optimized` | نسخهٔ بهینهٔ برنامه با ارائه‌دهندهٔ قابل تنظیم | `.env.local` | `npm run dev:optimized` |
| `boxapi` | نسخهٔ آمادهٔ اتصال به سرویس هکاتون BoxAPI | `.env.boxapi.local` | `npm run dev:boxapi` |

**هر دو نسخه مسیر LLM دارند.** تفاوت آن‌ها تنظیمات اجرا و بسته‌بندی است، نه دو منبع متفاوت برای کالا و قیمت. نبود کلید باعث فعال‌شدن حالت قطعی با برچسب واضح می‌شود. ساخت دیتابیس یک عملیات نصب است؛ هنگام بازکردن سایت، CSV دوباره خوانده یا برای مدل ارسال نمی‌شود.

## شروع سریع

نیازمندی: **Node.js 22+، npm و Python 3**. فایل ZIP اصلی دیتاست را جداگانه در `data/raw/torob-dataset.zip` قرار دهید؛ اعضای ZIP باید شامل `torob-dataset/products.csv`، `shops.csv` و `offers.csv` باشند. داده و کلید در بستهٔ سورس نیستند.

```bash
npm ci
# فقط در نصب تازه؛ فایل تنظیمات موجود را بازنویسی نکنید.
cp .env.example .env.local
npm run db:migrate
npm run data:audit
npm run data:import
npm run dev:optimized
```

برنامه: [localhost:3100/chat](http://localhost:3100/chat). مسیر `/` نیز همین تجربه را باز می‌کند. مسیرهای `/map`، `/products/[id]`، `/shops/[id]`، `/compare`، `/visit-plan` و `/settings` از همان داده استفاده می‌کنند.

### اتصال BoxAPI

```bash
# فقط برای نصب تازه
cp .env.example .env.boxapi.local
```

داخل فایل خصوصی `.env.boxapi.local`، کلید را در `AI_API_KEY` وارد کنید. فایل در Git و ZIP انتشار قرار نمی‌گیرد. تنظیمات زیر در نمونه موجودند:

```dotenv
AI_API_KEY=
AI_PROVIDER=boxapi
AI_BASE_URL=https://ai.boxapi.ir/ai/v1
AI_MODEL=gpt-6-luna
EMBEDDING_ENABLED=false
```

```bash
npm run ai:check       # فقط کشف مدل‌ها؛ آزمون پاسخ یا ابزار مدل نیست
npm run dev:boxapi
```

نشانی پیش‌فرض پروفایل BoxAPI: [localhost:3101/chat](http://localhost:3101/chat). در نمونهٔ تنظیمات، `PORT` و `NEXT_BUILD_DIR` را خالی بگذارید تا پیش‌فرض هر پروفایل اعمال شود. `NEXT_PUBLIC_APP_URL` را با نشانی اجرای خود هماهنگ کنید. کلید مدل فقط به سرور می‌رود. فهرست مدل‌های مجاز هکاتون از پنل مالک تعیین می‌شود؛ مدل پیش‌فرض بر اساس اطلاعات ارائه‌شدهٔ هکاتون تنظیم شده است. [مستندات رسمی BoxAPI](https://boxapi.ir/docs/ai/) مبنای Base URL و endpoint است.

نسخه‌ها از DB مشترک استفاده می‌کنند. **دو سرور را هم‌زمان روی یک پوشهٔ PGlite اجرا نکنید.** برای اجرای هم‌زمان از PostgreSQL مشترک با `DATABASE_URL` یکسان، یا از دو پوشهٔ PGlite واردشدهٔ جدا استفاده کنید.

### اجرای نسخهٔ ساخته‌شده

```bash
npm run build:optimized
npm run start:optimized
# یا پس از توقف نسخهٔ اول
npm run build:boxapi
npm run start:boxapi
```

`bash START_LOCAL.sh optimized` و `bash START_LOCAL.sh boxapi` در صورت نبود build، ابتدا آن را می‌سازند. پس از تغییر کد، build را دوباره اجرا کنید.

## داده و اعتماد

ممیزی کامل ورودی این workspace:

| جدول | تعداد رکورد |
| --- | ---: |
| کالا | 225,903 |
| فروشگاه | 6,476 |
| پیشنهاد | 331,506 |

قیمت‌ها **تومان و ثبت‌شده** هستند؛ موجودی و قیمت امروز تأیید نشده‌اند. فقط رکورد `offers` رابطهٔ محصول و فروشگاه را اثبات می‌کند. ساعت کاری، گزارش‌شده است. `payment_options.channel=unknown` واجد اقساط حضوری نیست. همهٔ تلفن‌های دیتاست ساختگی و بیشتر نام فروشندگان ناشناس‌اند؛ تماس واقعی با این شماره‌ها انجام نمی‌شود. مقدار غایب «نامشخص» می‌ماند.

مدل نمی‌تواند رکورد یا قیمت دلخواه بسازد: خروجی ابزارها با Zod کنترل می‌شود، پیشنهادهای نهایی به شناسه‌های مشاهده‌شده محدودند و کارت‌ها از اشیای معتبر دیتابیس ساخته می‌شوند. HTML مدل اجرا نمی‌شود. در نبود پاسخ کامل مدل، حالت جایگزین صریح است. امبدینگ برای این جریان اجباری نیست و ساخت انبوه بردار خودکار انجام نمی‌شود.

## ساختار پروژه

```text
src/
  app/                 صفحات و APIهای Next.js
  components/          چت، کارت‌ها، نقشه و جریان‌های خرید
  lib/
    agent/             ابزارها، اتصال مدل و هماهنگ‌کنندهٔ پاسخ
    db/                PGlite/PostgreSQL، schema و indexها
    retrieval/         بازیابی معنایی اختیاری
    contact/           پروندهٔ استعلام و شبیه‌سازی
    journeys/          برنامهٔ مسیر و اتصال اختیاری نشان
scripts/               ورود داده، ممیزی، اجرای پروفایل و بسته‌بندی
public/                دارایی‌های رابط با منشأ مستند
tests/                آزمون‌های واحد، داده و مرورگر
docs/                 راهنما، معماری و ارائهٔ هکاتون
data/                 فقط محلی و خارج از Git: دادهٔ خام و DB
archive/              فقط محلی: بک‌اند قدیمی و manifest قبلی
```

## بررسی و بسته‌بندی

```bash
npm run lint
npm run typecheck
npm test
npm run build:optimized
npx playwright install chromium
npm run test:e2e
npm run release:check
npm run release:optimized
npm run release:boxapi
```

ZIPها در `releases/` ساخته می‌شوند و فایل موجود را بازنویسی نمی‌کنند. بسته‌بندی با allowlist، اسکن کلید، منع symlink و manifest دارای SHA-256 انجام می‌شود. دیتاست، DB، تنظیمات خصوصی، بک‌اند قدیمی، node_modules و build داخل ZIP نیستند. [راهنمای انتشار](docs/release-package.md).
